# 🚀 دليل تشغيل تطبيق الهاتف (Elnagar Mobile)

## 1. إعداد السيرفر (الكمبيوتر الرئيسي)

1. تأكد من أن ملف `server_extensions.py` موجود في مجلد المشروع.
2. تأكد من أن ملف `app.py` يحتوي على السطر التالي:
   ```python
   from server_extensions import sync_bp
   app.register_blueprint(sync_bp)
   ```
   (تمت الإضافة تلقائياً بواسطة المساعد الذكي).
3. شغل السيرفر كالمعتاد:
   ```bash
   python app.py
   ```
4. **هام جداً:** يجب معرفة الـ IP الخاص بجهاز الكمبيوتر.
   - افتح موجّه الأوامر (CMD) واكتب `ipconfig`.
   - ابحث عن `IPv4 Address` (غالباً يبدأ بـ `192.168.1.X`).
   - هذا هو العنوان الذي ستستخدمه في تطبيق الهاتف.

---

## 2. تشغيل تطبيق الهاتف

1. **على الكمبيوتر (للتجربة):**
   - افتح نافذة جديدة وشغل:

   ```bash
   python mobile_app.py
   ```

   - سيظهر التطبيق بمظهر الهاتف.

2. **على الهاتف (Android):**
   - لتشغيل التطبيق على الأندرويد، تحتاج إلى تحويل كود بايثون إلى APK أو استخدام تطبيق "Flet" من المتجر (للمطورين).
   - الحل الأسرع حالياً هو تشغيله كـ **Web App (PWA)** على الشبكة المحلية:
     - عدل `mobile_app.py` في آخر سطر:
       ```python
       ft.app(target=main, view=ft.AppView.WEB_BROWSER, port=8550, host="0.0.0.0")
       ```
     - افتح متصفح هاتفك واكتب: `http://192.168.1.X:8550`.
     - (استبدل X برقم الـ IP الخاص بجهازك).

---

## 3. شرح الاستخدام

- **الوضع الافتراضي (Offline):** يمكنك إضافة طلبات والعمل بدون إنترنت. سيتم حفظها في قاعدة بيانات محلية `mobile.db`.
- **المزامنة (Sync):**
  - اضغط زر 🔄 في الأسفل.
  - سيقوم التطبيق برفع الطلبات الجديدة للسيرفر الرئيسي.
  - وسيقوم بجلب أحدث العملاء والمنتجات من السيرفر.
- **الحفظ:** البيانات تظل محفوظة على الهاتف حتى لو أغلقت التطبيق.

استمتع بتجربة احترافية! 🚀

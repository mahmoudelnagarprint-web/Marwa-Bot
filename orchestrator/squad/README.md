# فريق «النجار برنت» — Squad (الشخصيات والمجلدات)

> التوثيق البشري للفريق تحت إدارة **مروة**.
> **مصدر الحقيقة الآلي للأسماء: `../router.py`** (جدول `_PERSONAS`) — أي تعديل في
> الأسماء أو قواعد النداء يتم هناك أولاً ثم يُوثَّق هنا.
> الكود التنفيذي لكل وكيل باقٍ في مكانه الأصلي `../agents/` (قرار معماري:
> صفر تغيير استيراد — نقل الملفات يكسر الاكتشاف التلقائي).

## قاعدة النداء (الملخص التنفيذي)
1. **«يا <اسم>» في أي موضع بالرسالة (بداية أو وسط) = توجيه قاطع** — أول نداء يفوز.
2. **أسماء الدلع تعمل سافرة بدون «يا»**: صاصا، فيجن، كوكو، بيبو، راصد
   (فحص 2026-10-17: صفر عملاء بهذه الأسماء من إجمالي 52 عميلاً).
3. **الأسماء الشائعة لا تعمل إلا مع «يا»**: مصطفى، فارس، سلمى، حكيم — حماية من
   التصادم مع أسماء عملاء حقيقيين (موجود فعلاً: عميلة «مروه العمده» id 16).
4. **«مروة» = الوكيل الأصلي (AGENT.md)** — بطاقة تعريف فقط، ولا تُمرَّر لأي
   وكيل فرعي أبداً (قرار المالك 2026-10-16).
5. **لو مفيش اسم**: مروة تحلل الطلب وتكلف الوكيل المناسب تلقائياً (سلوك core.py).

## محتوى كل مجلد
- `AGENT_PROFILE.md` — دستور الوكيل: هويته، دوره، علاقته بمروة، كلمات الاستدعاء،
  الأدوات والجداول المسموح بها، وحدود العمل.
- `CHAT_BOOTSTRAP_PROMPT.md` — برومبت جاهز للنسخ يفعّل شخصية الوكيل في نافذة
  شات مستقلة مخصصة له.

## اختبار سريع (من جذر المستودع)
```
python -m orchestrator.core --route "يا بيبو احسب ليزر 30 40"
python -m orchestrator.core --message "يا كوكو"
python -m orchestrator.core --route "مروه العمده عندها طلب؟"
```
آخر واحدة يجب أن تبقى **غير موجّهة** (ذكر عميلة، مش نداء) — دي المصيدة.

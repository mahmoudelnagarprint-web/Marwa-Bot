# 💡 النوتبوك الذكية (Smart Notebook) — النجار برنت

نوتبوك ذكية تحت إدارة **مروة**: تكتب أي حاجة بالعربي الحر، وهي تفهمها وتصنّفها وتفكّرك بيها.

## التشغيل
```bat
notebook\run.bat
:: أو
python -m notebook.app --port 8100
```
- من الجهاز: http://127.0.0.1:8100
- **من الموبايل على نفس الواي فاي:** http://192.168.1.15:8100 (IP الجهاز الحالي)

## بتعمل إيه
| القدرة | التفصيل |
|---|---|
| فهم النص الحر | تحدّد: 📝 نوت / ✅ مهمة / ⏰ تذكير / 💡 فكرة / 🚀 فكرة برنامج |
| تصنيف تلقائي | ليزر، طباعة، خامات، تصميم، عملاء، حسابات، مشتريات، صيانة، برامج، شخصي… **وتفتح تصنيف جديد لوحده** لو الكلام استدعى |
| استخراج الميعاد | «النهاردة»، «بكرة»، «بعد بكرة»، «بعد 3 أيام»، «يوم الأحد»، «الساعة 5»، «الساعة 9 الصبح»، «5 العصر»، «كل يوم/كل أسبوع/كل شهر»، وتواريخ مثل 20/10 |
| أولوية | عاجل / مهم / عادية / منخفضة من كلامك |
| سؤال توضيحي | لو مش فاهم نوع المدخل أو ناقص تصنيف/ميعاد، بيحفظ ويصحّح بيك بسؤال واحد |
| أفكار البرامج | أي كلام فيه «فكرة برنامج/تطبيق» → يتخزّن في تصنيف **أفكار برامج** مع أسئلة توضيح للمشروع |
| متابعة | سطح المكتب يعرض: ⏰ مستحق الآن، 🔴 متأخر، ❓ محتاج توضيح، 📋 القوائم والتصنيفات |

## القواعد الذكية
- «الساعة 5» = **5 العصر** (17:00)؛ لو عايز الصبح اكتب «الساعة 5 الصبح».
- التذكير تلقائيًا **قبل الميعاد بساعة**؛ تقدر تأجّل بزر «تأجيل ساعة».
- أي مهمة من غير ميعاد → بيسألك عن الميعاد (تقدر تحدّده من الواجهة).
- إشارة مرجعية: `#وسم` تتسجّل كوسم للبحث.

## واجهة برمجية (للالتقاط من أي مكان)
```
POST /api/capture   {"text": "فكرني بكرة الساعة 5 أسلّم الطلب", "source": "telegram"}
GET  /api/due       المستحق الآن + المتأخر
GET  /api/notes?status=open&kind=task&q=بحث
GET  /api/stats
GET/POST /api/categories
PATCH /api/note/<id>
GET  /health
```

## البيانات والنسخ الاحتياطي
- القاعدة: `notebook/data/notebook.db` (SQLite) — **منفصلة تمامًا** عن قاعدة البرنامج `pos_data.db` (مفيش أي كتابة على البرنامج).
- `*.db` و`backup/` مستبعدين من Git — بياناتك ما تطلعش على GitHub.
- النوتس على الويندوز محليًا؛ النسخة الأسبوعية للـWorkspace تشمل المجلد لو اتوسّعت لاحقًا.

## الملفات
- `store.py` — التخزين (SQLite + تصنيفات + أحداث).
- `brain.py` — العقل: التطبيع العربي، التصنيف، المواعيد، الأسئلة.
- `app.py` — واجهة الويب + الـAPI.
- `templates/index.html` + `static/style.css` — الواجهة الملونة RTL.
- `run.bat` — تشغيل سريع.

## المرحلة الجاية (بانتظار قرار المالك)
- قناة تليجرام: استقبال النوتس من أي مكان (polling) + إرسال التذكيرات.
- تشغيل تلقائي عند بداية الويندوز.
- مزامنة النوتس مع الخزينة السحابية (اختياري).

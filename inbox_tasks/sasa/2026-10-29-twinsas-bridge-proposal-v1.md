## 1) الهدف
من أي مكان (البيت / الورشة / الموبايل): تعطي مهمة لأي جهاز → صاصا ينفذها بدقة وبسرعة (ماوس/شاشة/برامج/أوامر) → **تقرير اكتمال موثق** يوصلك فورًا هنا وعلى تليجرام. الاتجاهين: من الورشة تتحكم في اللابتوب، ومن اللابتوب تتحكم في الورشة.

## 2) المبدأ الهندسي: صفر بناء جديد
المنظومة تملك بالفعل (مُتحقق منه بالكود):
- طابور `commands` سحابي يعمل + أفعال `open_app/screenshot/shutdown/reboot/orchestrate`
- **pywinauto 0.6.9 + pyautogui** مثبتة ومتحققة على الورشة (RPA Phase 1 — 17-10)
- تصميم **Pulse** كامل (استطلاع 3 ث + UDP nudge + Idempotency I1-I8) — مكتوب، غير مُشغّل، بانتظار موافقة المالك (§8 في وثيقته)
- تليجرام webhook (Replit) + `agent_tasks/agent_updates` (sasa مسموح بعد ترحيل 007)
- خزينة العقل `system_brain_sync` (فيها `env_backup`) + git ثنائي الاتجاه + pos-reader/pos-writer

**الجسر = تفعيل الموجود + 4 إضافات جراحية.** مفيش سيرفر جديد، مفيش خدمات جديدة.

## 5) أفعال الجسر (twinsas verbs) — بمستويات AGENT.md حرفيًا

## 9) الأمان — خريطة كاملة على دستور المنظومة
- **مستويات AGENT.md حرفيًا**: جدول §5 + صيغة التأكيد «سأفعل: [الفعل]. الأثر: [ما سيتغير]. أنفذ؟»
- **W1/W2**: الورشة كاتب القاعدة الوحيد عبر الدوال الرسمية؛ executor اللابتوب بلا أي مسار كتابة قاعدة إطلاقًا
- **W3/W4/W5**: لا حذف سحابي، لا force-push، لا أسرار في الكود أو اللوجات
- **I1–I8 (تصميم راصد)**: op_id (ULID) + CAS على status + applied_ops + lease الكاتب
- **الحساس**: إطفاء/إعادة تشغيل/إغلاق قسري = تأكيد صريح + مهلة إلغاء 60 ث
- **تدقيق كامل**: كل أمر = صف موثق بالنتيجة + report قابل للعرض في أي وقت

## 10) الحدود الصادقة
- الجهاز الهدف يجب أن يكون شغالًا وجلسته **مفتوحة** (قفل الشاشة يمنع UIA والطباعة)
- RPA **بالهوية لا بالإحداثيات** — عنصر بلا اسم = نُبلغ بصدق ونطلب عين المالك عبر Parsec
- UDP داخل الشبكة الواحدة فقط؛ عبر الإنترنت القناة = السحابة
- مسار النص العربي القديم (`orchestrate`) يبقى شغالًا للتوافق العكسي
- كتابات POS التجارية لا تتغير إطلاقًا (نفس القناة الرسمية)

## 11) سيناريو حي — مهمة Parsec تحت الجسر (بعد Phase 2)
1. اللابتوب: `uia_inspect {window:"Parsec"}` → الورشة تلتقط ~3 ث
2. رد JSON: عناصر نافذة Parsec بأسمائها → اختيار زر المشاركة
3. `uia_click {window:"Parsec", element:"..."}` → تنفيذ → لقطة تأكيد
4. **تقرير اكتمال للمالك خلال ~15 ثانية إجمالًا**

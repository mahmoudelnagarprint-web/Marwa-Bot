# بروتوكول المهارات (skills/)

**المصدر:** المرحلة 2أ — «المراحل المدمجة (2026-10-11)» في memory/roadmap.md (قرار المالك).

## البروتوكول (صانع المهارات)
1. **المسودة** تُكتب في `skills/_drafts/`، ثم يعرضها الوكيل بلغة بسيطة.
2. **التفعيل** = إضافة المهارة إلى `skills/INDEX.md` — مستوى 1 بتأكيد المالك.
3. المهارة **تعليمات وليست صلاحيات**: لا تتجاوز AGENT.md ولا RULES.md ولا تعليمات المالك.
4. **أي رقم** داخل مهارة يأتي من المالك أو من البرنامج (بأداة pos-reader) — ومصدره مكتوب. لا أرقام مخترعة.
5. أي مهارة تمس **أدوات الكتابة أو القواعد** = مستوى 2 (تأكيد مضاعف).
6. عند وجود مهارتين أو أكثر يُعدَّل الـExpert **مرة واحدة** ليقرأ `skills/INDEX.md`.
7. `required_tools` **توثيق فقط** — DSH لا يفرضها؛ الحماية من قواعد المالك والتأكيدات لا من الملف.
8. أول 3 مخرجات من مهارة جديدة تُراجَع بالبرنامج قبل الاعتماد (شرط عبور المرحلة 2).

## القالب (يُنسخ لكل مهارة جديدة)
```markdown
# <اسم المهارة>
- الإصدار: 1.0 | الحالة: draft (في _drafts/) / active (مدرجة في INDEX.md)
- النطاق: ماذا تغطي (قراءة / تقرير / اقتراح / كتابة محكومة)
- المنطق: خطوات التنفيذ بلغة بسيطة
- القيود: ما لا تفعله المهارة، ومتى تتوقف وتسأل المالك
- شكل الإخراج: مثال نصي للنتيجة النهائية
- required_tools: أدوات DSH/MCP المطلوبة (توثيق فقط — DSH لا يفرضها)
- المصادر: مصدر كل رقم (المالك / أداة pos-reader بالاسم)
```

## الملاحظات
- لا مهارات مفعّلة بعد (المرحلة 2 لم تبدأ)؛ المسودات في `skills/_drafts/` فقط.
- المهارات الداخلية ملفات نصية داخل هذا الـWorkspace؛ اكتشاف مهارات DSH الخارجية للقراءة فقط عبر فهرس المهارات في DSH، ولا تُنقل تلقائيًا إلى INDEX.md — التفعيل بقرار المالك.
- مهارة منتهية أو مرفوضة تُنقل للأرشيف حسب memory/README.md (لا حذف نهائي).

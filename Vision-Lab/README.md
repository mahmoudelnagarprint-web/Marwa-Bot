# 🔬 مختبر فيجن (Vision-Lab)

مساحة عمل مستقلة لوكيل الكودر «فيجن» لتطوير البرامج والمشاريع مع سيطرة كاملة على التحديثات لكل مشروع على حدة.

## ما هو هذا المكان؟
هذا المجلد هو مساحة عمل مخصصة لكوكيل الكودر (فيجن) donde يمكنك بناء وتطوير برامج ومشاريع البرمجيات مع ضمان أن كل مشروع يملك مستودع Git خاص به لتتبع تحديثاته بشكل منفصل. таким образом، يمكنك عمل تحديثات مختلفة لكل مشروع دون تأثير على الآخرين.

## كيف أبدأ مشروعًا جديدًا؟
استخدم السكربت المساعد داخل مجلد `scripts`:

```bat
python scripts\new_project.py اسم-المشروع
```

أو إذا كنت تفضّل استخدام ملف bat:

```bat
scripts\new_project.bat اسم-المشروع
```

سوف ينشئ لك مجلدًا تحت `projects\اسم-المشروع\` مع:
- تهيئة Git أولية (`git init`)
- ملف `README.md` أولي يوضح اسم المشروع وتاريخ الإنشاء
- ملف `.gitignore` أساسي لتجاهل ملفات البيئة وال.bytecode وملفات التخزين المؤقت
- مجلد `src\` بوضعية أولية (يمكنك إضافة الكود هناك)

بعد إنشاء المشروع، يمكنك الانتقال إلى مجلده وبدأ العمل:

```bat
cd projects\اسم-المشروع
# عدل الملفات، أضف الكود،等等
git add .
git commit -m "التحديث الأول: إضافة الهيكل الأساسي"
```

## كيف أجعل المشروع على GitHub (اختياري)؟
إذا أردت رفع المستودع إلى حسابك على GitHub (للمشاركة أو النسخ الاحتياطي):

1. اذهب إلى حسابك على GitHub وقم بإنشاء مستودع جديد (اختر خاصًا إذا كان يحتوي على كود أو بيانات حساسة).
2. داخل مجلد المشروع، شغّل:
   ```bat
   git remote add origin https://github.com/اسم-المستخدم/اسم-المستودع.git
   git branch -M main
   git push -u origin main
   ```
3. thereafter يمكنك رفع التحديثات عبر `git push` وطلب سحب pull request للتحديثات المهمة.

## ملاحظات هامة
- **كل مشروع هو مستودع مستقل**: تحديثات مشروع لا تؤثر على الآخر. هذا هو الغرض من هذه المساحة.
- لا تُCommit أي ملفات تحتوي على أسرار أو مفاتيح؛ استخدم `.gitignore` دائمًا.
- قبل أي commit، شغّل `py_compile` للتأكد من عدم وجود أخطاء بناء؛ السكربت الجديد لا يفعل ذلك تلقائيًا، لذا تذكر أن تفحص handويًا أو أضف خطوة فحص إلى روتينك.
- إذا واجهت أي Problema مع Git أو التزامات، راجع ملفات المساعدة أو اسأل الوكيل الرئيسي (مروة) لتوضيح.

## بنية المجلد
```
Vision-Lab\
├─ AGENT.md          # ميثادوك هذا المكان (وأنت تقرأه الآن)
├─ RULES.md          # قواعد العمل في هذا المختبر
├─ README.md         # هذا الملف
├─ STATUS.md         # الحالة الحالية للمختبر
├─ memory\           # ذاكرة 취ت لهذا المختبر (قرارات، ملاحظات)
│   └─ decisions_log.md
├─ projects\         # هنا كل مشروع يملك مستودع Git خاص به
│   ├─ project1\     # مثال: مشروع أول
│   │   ├ .git\      # مستودع Git مستقل
│   │   ├ README.md
│   │   ├ .gitignore
│   │   └ src\ ... 
│   └─ project2\     # مشروع ثاني
└─ scripts\          # سكربتات المساعدة
    └─ new_project.py  # أو new_project.bat لإنشاء مشروع جديد
```

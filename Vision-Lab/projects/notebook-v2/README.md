# 🧠 أفكاري (Afkary) — الذاكرة الثانية الاستباقية ومركز القيادة الموحد

> «Notebook v2» — مركز ينسّق منظومة النجار برنت كلها (المحل + الورشة + الوكلاء)،
> بوت تليجرام مستقل **@Afkary22Bot** للمالك فقط، مزودو ذكاء اصطناعي سحابيون قابلين
> للإدارة من الواجهة، وذاكرة مشتركة على PostgreSQL + pgvector تعمل من أي جهاز.
>
> **الأسماء:** النظام اسمه **«أفكاري»** · النداء **«فوفا»** · ولو قلت **«يا أفكار»** بيرد.
> (المصدر: `settings.persona_name` = «أفكاري» و`settings.persona_nick` = «فوفا»)

## 🗣️ فوفا بتفهم الفرق — ده أهم إصلاح في النسخة دي

**قبل:** أي رسالة تيجي (حتى «هاي») كانت بتتحوّل مهمة/نوت وتتسجّل في القاعدة. دليل حي:
صف في `captures` نصه **«هاي»** بـ`kind=note`.
**بعد:** بوابة نوايا (`nb/intent.py`) بتفرّق بين تلات حالات:

| النية | مثال | اللي بيحصل |
|---|---|---|
| `chat` | «هاي» · «عامل إيه» · «شكرًا» | رد ودود من فوفا — **صفر صف في القاعدة** |
| `capture` | «فكرني أدفع الكهربا بكرة 5» | يتسجّل، مع تأكيد عربي كامل |
| `command` | «/المهام» | أمر مباشر بلا تسجيل |

والبوابة على المزود السحابي المُعدّ — ومش بترجع للقواعد المحلية إلا لو **كل** المزودين السحابيين وقعوا.

## 🚀 تشغيل سريع (جهاز واحد)

```bat
:: 1) المتطلبات (مرة واحدة)
pip install -r requirements.txt

:: 2) إنشاء الجداول في Supabase (آمن للتكرار — idempotent)
python db\migrate.py

:: 3) تشغيل العقدة كاملة: ويب + بوت + استباقية + HA
python scripts\start_node.py
```

- الواجهة: `http://127.0.0.1:8110` (الصفحة الجديدة: **مزودو الـAI**)
- البوت: افتح **@Afkary22Bot** → `/start` → القائمة الرئيسية
- الإعدادات كلها من `.env` الجذر `G:\Marwa-Bot\.env` (انظر `.env.example`)

## 🖥️ وضع العقدتين (Workshop Desktop + Surface Pro 4)

شغّل نفس الأمر على الجهازين. كل عقدة:

1. تسجّل نبضة (`nodes`) وتحاول أخذ **عقدة القيادة** (`leader_lease`).
2. صاحب العقدة النشط هو الوحيد اللي يشغّل polling تليجرام + المهام المجدولة.
3. لو الجهاز القائد وقع: العقدة التانية تلتقط القيادة خلال ≤ 45 ثانية — البوت ما بيفصلش.

```bat
python scripts\start_node.py          :: على الجهازين — نفس الأمر
python scripts\health_sync.py        :: فحص صحة/مزامنة يدوي (تليجرام + Retail)
```

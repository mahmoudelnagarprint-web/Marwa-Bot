# 📐 قوالب الذكاء الاصطناعي — Vision-Lab (LAPTOP_NODE)

هذا المجلد يضم القوالب الجاهزة (Boilerplate) لأدوات التطوير الذاتي في المعمل.
كل ما هنا يُرفع تلقائياً للمزامنة عبر Git ليصل إلى جهاز الورشة — **بلا أي أسرار**.

## 1) قالب «طاقم تحليل المشاريع» (CrewAI)
- **الملف:** `crewai_project_analyst_template.py`
- **الطاقم:** ثلاثة وكلاء متسلسلين: مستكشف المشاريع ← مراجع الكود ← كاتب التقرير.
- **تشغيل فوري:**
  ```
  .venv\Scripts\python.exe ai_templates\crewai_project_analyst_template.py <مسار-المشروع>
  ```
- **النموذج اللغوي:** يُقرأ من متغيرات البيئة (`DAHL_*` أولاً ثم `OPENAI_*`)،
  ويُحمَّل تلقائياً وصامتاً من `.env` بجذر المستودع — لا مفاتيح داخل القالب إطلاقاً.
- **كيف تستخدمه مع مشروع جديد؟** استدعه مباشرة بمسار أي مشروع؛ لقطة البنية
  (شجرة ملفات + مقتطفات) تُجمع محلياً ببايثون قياسي وتُمرَّر للطاقم — لا حاجة لأدوات إضافية.
- **توسعة مقترحة:** `pip install crewai-tools` ثم إرفاق `FileReadTool/DirectoryReadTool`
  بالوكلاء لو أردتَهم يقرؤون الملفات بأنفسهم وقت التشغيل.

## 2) تكوين Aider
- **الملفات:** `../config/aider.config.yml` + المشغل `../scripts/run_aider.ps1`
- **البيئات (معزولة لتجنب تعارض الإصدارات):** `.venv/` لـ CrewAI • `.venv-aider/` لـ Aider — كلتاهما محليتان داخل المعمل ومستثنيتان من Git.
- **النموذج:** `zai-org/GLM-5.3-Flash` عبر بوابة DAHL (قابل للتبديل من التكوين).
- **التشغيل على اللابتوب:** `powershell -ExecutionPolicy Bypass -File scripts\run_aider.ps1 --message "..." [ملفات...]`
  (سياسة تنفيذ PowerShell تمنع `.ps1` افتراضياً — Bypass على مستوى الأمر فقط، دون تغيير النظام).
- المشغل يربط مفتاح DAHL من `.env` وقت التشغيل دون طباعته أو تخزينه داخل المعمل.

## قواعد صارمة لأي قالب جديد هنا
1. بلا مفاتيح ولا أسرار ولا توكنات — متغيرات بيئة فقط.
2. احترام `.gitignore` (الخاص بالمعمل + الخاص بجذر المستودع).
3. قابل للتشغيل فوراً: `python -m py_compile <الملف>` قبل أي مزامنة.

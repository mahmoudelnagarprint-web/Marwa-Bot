# scripts — أدوات Vision-Lab

## `win_ocr.ps1` — قراءة النص من أي صورة (محلي 100%)

يستخدم محرك OCR المدمج في ويندوز (`Windows.Media.Ocr`) — **بلا إنترنت، بلا مفاتيح API، بلا تركيب مكتبات**.

```powershell
# نص عربي (كلمة عربية واحدة داخل صورة إنجليزية كافية لسحب السطر كله)
powershell -NoProfile -ExecutionPolicy Bypass -File win_ocr.ps1 -Path "صورة.png" -Lang ar-SA

# نص إنجليزي/أرقام
powershell -NoProfile -ExecutionPolicy Bypass -File win_ocr.ps1 -Path "صورة.png" -Lang en-US
```

**قواعد مهمة (مُختبرة):**
1. للصورة **المخلوطة عربي + إنجليزي** شغّل السكربت **مرتين** — كل لغة تحتاج نموذجها الخاص، ودمج النتيجتين يعطيك السطر كامل.
2. الخط العربي يجب أن يكون **مناسب الحجم** (≈50px+ في صورة بعرض ≈1200). الخط الصغير جدًا (30px في صورة 1000px) **لا يُقرأ إطلاقًا** — كبّر الصورة أو أعد تصويرها أقرب.
3. مخرجات العربية ترجع بترتيب **بصري معكوس** (كما تراها العين على الشاشة، لا كما تُكتب) — لا تفترض أن الترتيب منطقي.
4. حدود المحرك: `MaxImageDimension = 10000px`، واللغات المتاحة على هذا الجهاز: **`ar-SA` و`en-US`** فقط.
5. قيّد ملف السكربت بـ **ASCII فقط** — PowerShell 5.1 يقرأ ملفات `.ps1` بترميز غلط لو فيها حروف عربية بدون BOM.

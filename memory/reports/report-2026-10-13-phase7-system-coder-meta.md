**المرحلة 6 (مدير التصنيع) مؤجلة رسميًا** حتى تجهّز جدول الخامات ومقاسات الألواح والهالك بتفاصيلها الدقيقة — لا يوجد جدول خامات في التطبيق أصلًا، فقرار الموقف لا تسعير مخترعًا. (roadmap.md + decisions_log #60) **والمرحلة 7 طلعت فورًا** ودي نتيجتها.

## 1) عامل النظام (system_worker.py)
| القدرة | كيف اشتغلت | النتيجة الحية |
|---|---|---|
| لقطة شاشة | mss → حفظ في cloud/ + إرسال لتليجرام المالك | أُدرجت في الطابور ثم pull-once نفّذها — pending=0 بعد التنفيذ |
| فتح برامج | notepad/cmd/calc/explorer مبرمجة؛ RDWorks/فوتوشوب تنتظر مسارك مرة واحدة | «افتح rdworks» → يطلب المسار بصدق (لا مخترع) + يحفظ في system_apps.json |
| فتح مجلدات | root/cloud/backups | مجلدات معروفة |
| حالة الجهاز | uptime/مساحة/mss/pyautogui | شغال ساعات متعددة، 30GB فاضية |
| **إطفاء/إعادة تشغيل** | حاجز كلمة تأكيد صريحة | «اطفئ الجهاز» → رفض ويتطلب «الجهاز تأكيد» + مهلة 60ث قابلة للإلغاء |
| أوامر الماكينة عن بُعد | إدراج في طابور commands (insert فقط) | ✅ E2E: screenshot → الطابور #2 → نفذ → الصورة لتليجرامك |
| **شريط التوجيه الطافي** | steering_bar.py (Tkinter, عائم دائمًا) — يتحمّل أعلى الشاشة، خلاصة حية، خانة توجيه سريع، Kill-Switch (Esc/منطقة حمراء)، Pause/Resume/Step | اتشغّل حيًا وظهر في قائمة النوافذ «مروة — شريط التوجيه» (ما زال يعمل الآن) |
| **UI Automation (بدون إحداثيات)** | pywinauto (شجرة إمكانية الوصول) — «قائمة النوافذ»؟، «شوف نافذة X» يعرض أزرار/حقول بأسمائها، «ضغط زر X في Y» بالنفس لا بالبكسل | «اعرض النوافذ المتاحة» عرض 12 نافذة حقيقية؛ «شوف نافذة فيها Taskbar» عرض أزراره (Start، ...) — كل ذلك بلا إحداثيات ثابتة ✓ |
| **GitHub Ingestion (الكودر)** | لا استنساخ ذاتي — بوابة موافقة: رابط → خطة (clone عمق-1 إلى tools\github\<repo> معزول + توليد wrapper) → «نزّل <URL> + أعتمد» | اختُبرت البوابة: خطة show بلا تنفيذ ✓ (لا تنزيل مخفي) |

## 2) الكودر (coder.py)
- **فحص صياغة + اكتشاف حقيقي**: 59 ملفًا فُحص — **خطأ أُمسك**: `sync_manager.py` سطر 15 `]` يتيمة (قوس لم يُغلق من تكوين قديم) — ملف مزامنة Google-Drive قديم مكسور فعلاً، إصلاحه أو حذفه بانتظار قرارك.
- **بحث الكود**: record_client_payment → 3 نتائج (السطور 418-419 في supabase_sync.py حقيقية + واحد في نص الكودر) — بعد إصلاح سقف الملفات ورابط مكسور عبر os.walk آمن.
- **GitHub Ingestion**: البوابة + المسار المعزول بنيتا واختُبرت (الخطة فقط؛ التحميل الفعلي بأمرك بالصيغة +أعتمد).
- **رصد الأخطاء**: غير موجّه 4، meta TypeError قديم (المصلوح سابقًا) — كل الوكلاء المبنية نظيفة.
- **Git**: مازال لا مستودع؟ — git init اقتراح بأمر المالك.
- **لا يعدّل أي كود ذاتيًا** — الاقتراح فقط.

## 3) المراقب الذاتي (meta_agent.py)
- **«تقرير الأداء»** (حيًا من السجل): غير موجّه 4 استدعاءات (100% خطأ=لم يتوجه)، meta 1 خطأ (16.7%)، الباقي صفر — cfo 9، coder 6، crm 6، data_healer 5، marketing 3، system_worker 3.
- **«اقتراحات التطوير»**: حلل السجل وحدد تلقائيًا الرسائل الأربع غير الموجّهة (فحص سريع/آخر استدعاءات/شطب دين احمد/امكانيات عامل النظام) ككلمات توجيه مقترحة — **و3 منها اتحل فعلًا بكلمات اليوم**. الدليل أن المراقبة الذاتية اشتغلت.
- كل التطبيقات (تعديل كلمات/تعليمات) تتم بموافقة المالك عبر DSH.

## إصلاحات وقعت أثناء البناء
- كلمات «امكانيات» أُضيفت لتوجيه النظام (كانت في الفروع لا الكلمات).
- بحث الكودر: سقف الملفات رُفع + تحوّل لـos.walk آمن يتجاهل رابطًا مكسورًا داخل مجلد أندرويد مؤرشف (كان يكسر الـFileNotFoundError بدل أن يواصل البحث).
- ترتيب فروع system_worker: الـUI-A (شوف نافذة/ضغط زر) قبل الإمكانيات والفتح كي لا تلتقطها كلمات مثل «المتاحة» و«rdworks»؛ وشرط «عرض النوافذ» كان يلتهم كل رسالة (صُحح بـ `in t`).
- فحص نافذة Taskbar: تعديل تمرير control_type كسلسلة منفصلة لكل نوع بدل قائمة (pywinauto يرفض القائمة).
